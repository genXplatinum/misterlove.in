# Site maintenance, 10 November 2026

The default White edition and the Original edition share public media URLs.
`postbuild-editions.mjs` moves route HTML, leaves shared assets in place, and
retains the older Original asset aliases. Validate **after** all renderers and
edition transforms; checking the intermediate Press build misses this failure.

Audio was retired at the author's request. Do not add recordings to this Git
repository. Old Listen/Podcasts entry points redirect to the writing archive.
All written research, translations, PDF downloads and print cover masters stay.
Use a fresh clone after the audio history rewrite; merging an old clone can
reintroduce the removed history even when its current tree contains no audio.

Responsive book covers are generated by Sharp from untouched print masters
during prebuild. Both server rendering and React use the same srcset definitions.
Generated derivatives are not committed. Keep sizes aligned with CSS layouts.
The White edition loads its own fonts; Original's font CSS is route-scoped.
The blocking brand introduction is no longer loaded.

The final security pass adds a Content Security Policy to every HTML document,
including aliases and the 404. Inline scripts have per-document SHA-256 hashes;
inline event handlers and plugins are blocked. Inline styles remain permitted
for existing React styles and static layouts. The dictionary API is explicitly
allowed. No claim is made that a dependency audit proves an absence of exploits.

GitHub Pages does not provide configurable response headers here. The CSP and
referrer policy are document-level policies. HSTS comes from the host. Response
header controls such as `frame-ancestors`, `X-Content-Type-Options`, a Permissions
Policy and custom immutable caching require a hosting/edge configuration change;
they are not simulated with an ignored `_headers` file or unsupported meta tags.

Required checks:

```
npm ci
npm audit --audit-level=high
npm run lint
npm run build
node scripts/verify-performance.mjs
node scripts/verify-white-premium.mjs
git diff --check
```

Build includes final-tree validation of local images, styles, scripts, links,
PDF byte integrity, CSP hashes, no stored audio and a 500 MB deployment budget.
After deployment, verify images, both editions and languages, master PDF hashes,
sitemap/RSS and retired routes on the public domain. Also check browser console,
mobile navigation/search and reader layout.

GitHub retains read-only pull-request references and may cache old Git objects.
Rewriting branch history cannot erase other people's clones or guarantee backend
garbage collection. Report branch-history removal separately from those limits.
